## 🚀 Featured Projects

### 🦷 [SmileCare Dental Clinic](https://noor-fatima-portfolio-two.vercel.app/projects/smilecare-dental-clinic)

An AI-powered dental receptionist designed to help clinics capture and manage patient inquiries outside working hours.

**React • TypeScript • Tailwind CSS • Gemini • Make.com • Google Sheets • Twilio • Vercel**

The system collects patient information and appointment preferences, logs leads, and sends instant WhatsApp notifications to help clinics respond to potential patients.

---

### 🌱 [Sohan-Agri](https://github.com/NoorayFatima/Sohan-Agri-final)

An intelligent agricultural platform combining plant disease diagnosis with practical agricultural assistance.

**Python • TensorFlow • Keras • MobileNetV2 • Flask • PWA**

The project includes image-based plant disease detection, agricultural information, pesticide calculation, market-price data, Urdu/English support, text-to-speech, and offline-first functionality.

### 📚 [Folio](https://noor-fatima-portfolio-two.vercel.app/projects/folio)

A premium MERN-based knowledge vault designed for developers and researchers.

**Next.js • TypeScript • Tailwind CSS • Node.js • Express • MongoDB**

Features include authenticated research workflows, rich-text notes, dynamic tagging, global search, and structured content management.
